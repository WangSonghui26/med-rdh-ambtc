# Test images

Place the twelve standard 512x512 grayscale BMP benchmark images here before
running the experiments. They are NOT redistributed in this repository for
copyright reasons; all are publicly available benchmark images (e.g. from the
USC-SIPI dataset or standard steganography toolboxes).

Expected layout and file names (keep them exactly as listed):

    pics/
      pics/1-Baboon.bmp
      pics/1-airplane.bmp
      pics/4-Peppers.bmp
      pics/5-elaine.bmp
      pics/8-wine.bmp
      pics/10-girl.bmp
      pics2/2-Barbara.bmp
      pics2/3-Lena.bmp
      pics2/6-Goldhil.bmp
      pics2/9-boat.bmp
      pics2/11-tiffany.bmp
      pics2/12-zelda.bmp

All images must be 512x512, 8-bit grayscale, Windows BMP (.bmp). If your copies
are PNG or a different size, convert them to 512x512 grayscale BMP and rename to
match the list above.
